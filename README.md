# 提前退休计算器

[通过网页访问。](https://retirement.wangyufeng.org/)

提前退休计算器是一个用于估算提前退休所需储蓄和投资回报的工具。通过输入当前年龄、提前退休年龄、法定退休年龄、规划截止年龄、每月开销、当前储蓄、年投资回报率、通货膨胀率、预计退休金和法定退休时的期望储蓄，计算器会帮你估算所需的总储蓄、每月储蓄金额、压力测试结果以及储蓄增长曲线。

本工具基于 [Vite](https://vitejs.dev/) 和 React 构建。

## 开发

```
git clone https://github.com/wangyufeng0615/early_retirement_calculator.git
cd early_retirement_calculator
npm install
npm start
npm run deploy  # 部署
```
